# Legacy local music

Scheduled renders no longer select files from this directory. They retrieve sad-piano audio from Openverse and accept only CC0/Public Domain results.

The existing files are retained only as legacy assets. A local file can still be supplied explicitly with `scripts/render_short.py --music-file PATH` for an offline smoke test.

Music is mixed at low volume with a one-second fade-in and two-second fade-out.
